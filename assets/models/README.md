# 3D-Gebäudemodelle (.glb)

Lege hier echte 3D-Modelle als **`<gebäude-id>.glb`** ab – die Karte lädt sie
automatisch und zeigt sie statt der prozeduralen Platzhalter-Modelle.

- Format: **glTF-Binary (.glb)**, möglichst **unkomprimiert** (kein Draco/Meshopt).
- Ausrichtung: Modell „steht" auf dem Boden (Unterkante unten). Größe egal –
  es wird automatisch auf die Kachel skaliert (zentriert, Grundfläche ~1 Kachel).
- Fehlt eine Datei, bleibt einfach das prozedurale Modell sichtbar.

## Erwartete Dateinamen
- metalMine.glb
- crystalMine.glb
- deuteriumSynth.glb
- solarPlant.glb
- fusionPlant.glb
- metalStorage.glb
- crystalStorage.glb
- deuteriumTank.glb
- roboticsFactory.glb
- naniteFactory.glb
- shipyard.glb
- researchLab.glb
- allianceDepot.glb
- terraformer.glb

## Woher kostenlose Modelle?
CC0-Quellen (frei nutzbar): Kenney (kenney.nl), Quaternius (quaternius.com),
Poly Pizza (poly.pizza). Pack runterladen, passende Gebäude als `.glb`
exportieren/umbenennen und hier ablegen.
